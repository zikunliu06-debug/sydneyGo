# SydneyGo

移动优先的悉尼公共交通 UX 原型，采用 React、TypeScript、Vite、Tailwind CSS、React Router、MapLibre GL JS 和 Lucide。所有应用界面为英文。以 390 × 844 为主要视口，桌面居中显示，支持游客直接规划。

## 安装和运行

需要 Node.js 22 或更高版本（此环境验证版本为 24.19.0）。

```bash
cd /workspace/sydneyGo
npm install
npm run dev
```

依赖已经在当前云环境安装。日常开发只需运行 `npm run dev`。Vite 默认端口 5173，被占用时会选择下一个端口。

```bash
npm run build       # TypeScript 检查 + 生产构建，输出 dist/
npm run preview     # 本机预览生产构建
npm test            # Playwright 浏览器测试
```

复现锁定依赖请使用 `npm ci`。部署 `dist/` 时，静态托管服务需要把不存在的路径回退到 `index.html`，以支持 React Router 深链接。

## 页面和导航

欢迎 → 登录 / 注册 / 游客 → 个人资料设置 → Plan。Plan 提供可编辑的起点与终点、当前位置、保存 Home、明确起点确认和搜索建议。确认起点 → 三条路线比较 → 路线详情 / 地图 / 收藏与关注。

Map → 事故标记或拥堵路段 → 事故详情 → 替代路线 / 事故专属 Live Chat。切换路线会更新所选旅程。可以模拟事故解决，聊天随后只读。

Community 提供独立的长期讨论：搜索、分类、发帖、照片、详情、评论、Helpful 与举报。Profile 可修改资料，查看收藏、关注服务和自己发布的帖子，调整紧凑布局或退出。

底部始终提供 Plan / Map / Community / Profile。刷新按钮重新加载地图，不会伪造新的事故报告时间。

## 数据与外部服务

| 服务                      | 用途                                                      | API Key                             |
| ------------------------- | --------------------------------------------------------- | ----------------------------------- |
| `tile.openstreetmap.org`  | 真实 OpenStreetMap 栅格底图，保留可见署名                 | 不需要                              |
| `photon.komoot.io`        | 按需搜索 OpenStreetMap 地点，限制悉尼周边，输入延迟 700ms | 不需要                              |
| `router.project-osrm.org` | 可选的真实道路驾驶参考路线及距离                          | 不需要                              |
| Browser Geolocation       | 用户授权后的当前位置                                      | 不需要，部署时需 HTTPS 或 localhost |

目前无需配置密钥或 `.env`。真实道路参考需用户在路线结果页点击按钮获取；不是公交路线，不包含实时交通、公交 ETA 或步行导航。网络错误时会明确提示并保留默认流程。地点搜索始终保留预置的 UTS、Central、Town Hall、Broadway 等悉尼建议，这些建议标注为 curated，而非假装在线搜索成功。

这是小规模课程原型，不批量下载或离线缓存 OSM 瓦片。使用瓦片时遵守 https://operations.osmfoundation.org/policies/tiles/ ，保持署名和正常浏览器 Referer。公开部署或大规模使用应改用合适的商业瓦片服务或自建服务，并遵循各服务配额与条款。

**云环境限制：** 本次检查中这三个公共服务的直接请求被出站代理拒绝（403）。代码和错误回退已实现，MapLibre 地图控件、标记和模拟路线交互已进行浏览器测试，但真实底图、在线地理编码和在线道路数据在此机器中尚未验证成功。三个域名已加入环境配置草稿；请在环境设置中保存网络配置后重试，再发布环境。草稿保存本身不会改变当前机器的网络策略。

## 模拟数据与原型边界

- 三条公交/轻轨路线及路线线段是 Glebe → UTS 课程场景的示意。更改地点后仍显示这三种示例方案，**不是针对任意目的地计算的公共交通导航**。
- Total Journey Time 与 Next Bus Arrival 分开显示。总时长包含示例等待、步行及标示延误；预计到达按当前时间计算，始终注明为模拟，显示使用悉尼时区。
- Broadway 的事故、Bus 370 约 12 分钟延误、红黄绿交通线和初始聊天/社区内容均为模拟数据，非官方交通信息。场景时间戳固定，不假装最新实时更新。
- 照片、聊天、评论、收藏、关注、资料和举报保存于当前浏览器的 localStorage。聊天为单设备体验，不会发给其他通勤者；举报没有服务端审核。清除浏览器数据会丢失内容。
- 登录仅为本地演示。密码以 SHA-256 摘要保存，缺少生产认证的服务端、盐值、会话保护等，**请勿使用真实密码或敏感资料**。可直接使用 Guest，不强制注册。
- 图片限 2 MB；分享前避免面孔、车牌和个人信息，聊天图片必须填写说明。存储空间不足会显示保存失败提示。
- 不提供真实 Transport for NSW 公交时刻、实时事故、多人聊天或可靠的逐步公交导航。下一阶段需要官方/授权数据源、服务端及安全认证。

## 测试

`npm test` 自动启动 Vite，并使用 Chromium 测试移动端。此云环境使用 `/usr/bin/chromium`；其他机器可执行 `npx playwright install chromium`。也可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定已安装的浏览器。

浏览器测试包含四个完整可用性场景，以及社区发帖评论/有用标记、注册与资料保存再登录、定位拒绝和定位成功、事故解决后的只读聊天、图片说明与持久化、移动端无横向溢出、桌面宽度、运行时异常检查。

在线搜索与 OSRM 的成功响应处理使用 API fixture 验证，另外验证服务失败后的回退；fixture 测试不代表外部服务在此环境可用。真实外部服务限制见上。

## 项目结构

- `src/pages/`：规划、登录、路线、地图、事故、聊天、社区、个人资料页面
- `src/components/`：地图、路线卡、通用标题/标签、地点搜索和照片控件
- `src/services/`：地理编码、定位、道路路线、本地存储
- `src/data/demo.ts`：显式标注的示例数据
- `src/state.tsx`：共享旅程与本地持久化状态
- `tests/scenarios.spec.ts`：端到端浏览器测试

开发使用现有隔离仓库，无需创建 Git worktree。
